jevandezande / pixi-cookiecutter Cookiecutter for setting up python projects with pixi that just work

  • Packaging with [pixi](https://prefix.dev/)
  • Environment loading with [direnv](https://direnv.net/)
  • Formatting and linting with [ruff](https://github.com/charliermarsh/ruff)
  • Static typing with [ty](https://github.com/astral-sh/ty)
  • Testing with [pytest](https://docs.pytest.org/en/latest/)
  • Git hooks that run all the above with [pre-commit](https://pre-commit.com/)
  • Continuous integration with [GitHub Actions](https://github.com/features/actions)
  • Code coverage with [Codecov](https://docs.codecov.com/docs)
  • notes.md lists optional dependencies:
    • act runs GitHub Actions locally.
    • direnv can auto magically load environment variables and the pixi shell. 👎 direnv is not optional.
    • GitHub-CLI can create and manage a GitHub repository. Journal 2026-05-01 evaluates GitHub-CLI. 
      OSError: direnv is not installed; install with `pixi global install direnv`
  • 👎 tests/ includes __init__.py.
  • 👎 The python package is not isolated in src/.
  • 👎 Platform does not include "win-64".
  • 👍 Performs linting, formatting, type checking, and testing, using pre-commit, with repo: local.
  • 👍 Replace Makefile with pixi tasks.
